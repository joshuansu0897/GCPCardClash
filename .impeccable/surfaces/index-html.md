# Main Playboard & Curriculum Surface

- **Scope**: Single-page interactive application (`index.html`, `src/main.tsx`)
- **Visitor Mode**: Operate
- **Audience & Job**: Cloud engineers, developers, and GCP certification candidates practicing architectural topology decisions and service trade-offs in short sessions.
- **Primary Task & Proof**: Select a Google Cloud architecture scenario across 4 tracks, play Provisioning Energy, GCP Service, and Security cards onto a live block-diagram topology against an AI Rival (or switch to Guided Study/Inspect mode), and read immediate architectural feedback on every valid placement, anti-pattern mistake, or unshielded vulnerability.
- **Constraints**: 100% client-side React 19 + TypeScript + Vite; native `<dialog>` only where modal focus is warranted; inline inspector drawer for zero-interruption card and slot reading; keyboard-operable card-to-slot deployment alongside pointer click/drag.
